#### Projeto de Estrutura de Dados usando Python
<br>

##### Resumo do Problema:

- Baralho tradicional de 52 cartas
- Divide-se as cartas do baralho, igualmente, para dois jogadores. 
- A menor carta é o Ás e a maior é o Rei. Não importa o naipe. 
    => ["As","2","3","4","5","6","7","8","9","10","valete","dama","rei"]

- Cada jogador inicia com seu próprio conjunto de cartas empilhadas, viradas para baixo.
 
- A batalha começa quando cada jogador retira uma carta do topo do seu baralho e a revela na mesa.

- Aquele que apresentar a carta de maior valor, vence a batalha e recebe a carta do outro jogador. 

- As duas cartas são adicionadas à base do baralho. 

- No caso de cada jogador apresentar a mesma carta, elas ficam bloqueadas e outro par de cartas é puxado. 

- Ganha o total de cartas acumuladas(bloqueadas), o jogador que desempatar a batalha.
